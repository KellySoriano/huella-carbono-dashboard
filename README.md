## 🧭 Descripción breve del proyecto
Dashboard interactivo desarrollado en React para analizar emisiones anuales de CO₂ por país y su relación con **PIB** y **población** usando datasets de *Our World in Data*.  
Incluye: filtrado por país/año, métricas clave (CO₂ total, CO₂ per cápita, PIB per cápita, población), y visualizaciones (series de tiempo y comparativas).
